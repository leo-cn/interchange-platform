# interchange-platform 接口清单

> 生成时间：2026-09-26。来源：扫描 `src/main/java/com/interchange/platform/controller` 下全部 Controller。
> 端口默认 **18080**（`start.bat` → mysql profile → `t6` 库）。

## 一、运行时对外接口（给外部系统调用，不走登录会话）

| 接口 | 方法 | 鉴权 | 功能 |
|---|---|---|---|
| `/api/oauth/token` | POST | appKey/appSecret（`api_token` 表） | 请求方换票：凭证换有时效的 `AT-` 令牌（内存签发，verify 只查缓存） |
| `/api/oauth/revoke` | POST | 无 | 注销令牌（重置密钥/收窄权限/停用接入方时也会整批注销） |
| `/api/receive/{apiCode}` | POST/GET | 按 `receive_api.auth_required`（Bearer 令牌或免鉴权） | **数据接收运行时端点**：apiCode 必须先在 `receive_api` 表登记，未登记/停用 → 401「接口未定义」 |
| `/api/receive/health` | GET | 免鉴权（内网探针） | 接收通道健康检查 |

## 二、任务管理（登录后，页面用）

| 接口 | 方法 | 功能 |
|---|---|---|
| `/api/task/save` | POST | 新建/保存推送任务（SQL/拉取源 → 目标第三方） |
| `/api/task/toggle` | POST | 启用/停用任务 |
| `/api/task/run` | POST | 手动立即执行一次 |
| `/api/task/delete` | POST | 删除任务 |
| `/api/task/preview` | POST | 试跑取数 SQL，预览要推送的数据 |
| `/api/task/cron-preview` | POST | 解析 cron 表达式，预览未来执行时间 |
| `/api/task/detail/{id}` | GET | 任务详情（编辑页回显） |
| `/api/task/datasources` | GET | 可选数据源列表（main / t6 …） |

## 三、第三方系统（出站目标）管理

| 接口 | 方法 | 功能 |
|---|---|---|
| `/api/partner/save` | POST | 保存第三方（baseUrl、认证方式 NONE/BASIC/BEARER/API_KEY/HEADER、公共头、超时） |
| `/api/partner/toggle` | POST | 启用/停用 |
| `/api/partner/delete` | POST | 删除 |
| `/api/partner/detail/{id}` | GET | 详情回显 |

## 四、接收接口登记（入站清单）

| 接口 | 方法 | 功能 |
|---|---|---|
| `/api/receive-api/list` | GET | 已登记接收接口列表（60 秒缓存） |
| `/api/receive-api/save` | POST | 登记/编辑接口（apiCode、auth_required、说明）；save/toggle/delete 即时失效缓存 |
| `/api/receive-api/toggle` | POST | 停用/启用（停用 → 该 apiCode 立即 401） |
| `/api/receive-api/delete` | POST | 删除登记 |
| `/api/receive-api/detail/{id}` | GET | 详情回显 |

## 五、接口令牌（接入方凭证，出站调用方管理）

| 接口 | 方法 | 功能 |
|---|---|---|
| `/api/token/save` | POST | 新建/编辑接入方（appKey `AK-` /appSecret、allowApiCodes、ttl） |
| `/api/token/toggle` | POST | 启用/停用（停用 → 名下已签发令牌一并注销） |
| `/api/token/reset-secret` | POST | 重置 appSecret 并注销全部已签发令牌 |
| `/api/token/delete` | POST | 删除接入方 |
| `/api/token/issue` | POST | 页面内联调换票（拿该凭证签一个 access_token 看看） |
| `/api/token/active` | GET | 当前内存中有效的 `AT-` 令牌列表（不落库，重启清空） |
| `/api/token/detail/{id}` | GET | 详情回显 |

## 六、日志查询与导出

| 接口 | 方法 | 功能 |
|---|---|---|
| `/api/log/{id}` | GET | 推送执行日志详情（含请求/响应报文） |
| `/api/log/{id}/download` | GET | 单条执行日志下载 TXT |
| `/api/log/download` | GET | 按筛选条件批量导出（TXT/CSV，上限 10000 条） |
| `/api/receive-log/{id}` | GET | 接收日志详情 |
| `/api/receive-log/download` | GET | 接收日志批量导出 |
| `/api/iface-log/list` | GET | 接口日志文件列表（logs/interfaces 下，含 .gz 归档） |
| `/api/iface-log/trace` | GET | **按 traceId 定位一次执行**（兼容执行级 `traceId=xxx` 与报文级 `"traceId":"xxx"`，可带 date 限定） |
| `/api/iface-log/view` | GET | 看某接口日志文件末尾 N 行 |
| `/api/iface-log/download` | GET | 下载整个日志文件（≤50MB） |
| `/api/iface-log/clear` | POST | 清空某接口日志（截断当前文件 + 删当天分片 + 删归档） |

## 七、登录与个人

| 接口 | 方法 | 鉴权 | 功能 |
|---|---|---|---|
| `/login` / `/doLogin` / `/logout` | GET/POST/GET | 免登录 | 登录页 / 登录（t6 业务库账号 + ext 角色）/ 登出 |
| `/api/profile/token` | POST | 登录 | 重置**本人**接口令牌（第三方以个人身份调接收接口时用） |
| `/api/profile/password` | POST | 登录 | 修改本人口令（platform_password，BCrypt） |

## 八、系统

| 接口 | 方法 | 功能 |
|---|---|---|
| `/api/system/health` | GET | 存活探针（含库连接状态） |
| `/api/system/info` | GET | 版本/构建信息 |

## 九、内置联调 Mock（模拟第三方，仅本机联调用）

| 接口 | 方法 | 功能 |
|---|---|---|
| `/api/mock/thirdparty/order/push` | POST | 模拟第三方接收推送（回执 received=true + traceId） |
| `/api/mock/thirdparty/ping` | POST | 模拟第三方 ping 接收 |
| `/api/mock/thirdparty/health` | GET | Mock 健康检查 |

## 十、页面路由（Thymeleaf，shell.html 外壳 + 多标签）

`/`、`/dashboard`、`/task/list`、`/task/edit`、`/log/list`、`/receive/list`、`/iface-log/list`、`/partner/list`、`/receive-api/list`、`/token/list`、`/profile`

## 鉴权速查

- **管理接口（二~六、七、八）**：WebConfig 拦截 `/**`，凭登录会话；只读角色禁写操作。
- **运行时接口（一）**：免登录，靠令牌/登记约束（oauth 两个端点在 WebConfig 显式放行）。
- **Mock（九）**：也走登录拦截（同域测试时带会话即可）。
