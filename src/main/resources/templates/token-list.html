调用流程（请求方视角）
1. 换票：用 appKey / appSecret 换一个有时效的 access_token（令牌只在服务端缓存里，不落库）
curl -X POST http://127.0.0.1:18080/api/oauth/token \
  -d "appKey=AK-xxxx" -d "appSecret=xxxx"
返回 {"code":0,"data":{"access_token":"AT-…","expires_in":7200,"expire_at":"…"}}
2. 带令牌调接口：
curl -X POST http://127.0.0.1:18080/api/receive/order-receive \
  -H "Content-Type: application/json" -H "X-Token: AT-…" -d '{"bizNo":"A001"}'
也支持 Authorization: Bearer AT-…。令牌到期后重新换一次即可； 泄露时点「停用 / 重置密钥」，该接入方名下所有令牌立刻失效。
前置条件：被调用的 apiCode 要先在「接收接口」页登记过， 否则第一步就返回 401「接口未定义」。本页只管谁能调，接口存不存在由那张清单决定。
平台还认另外两种令牌做兜底：全局令牌 app.receive-token（所有人共用，仅内网联调）、 账号令牌 sys_user_ext.api_token（跟着人走）。
